# 🏪 Интернет-магазин на Django

Учебный проект интернет-магазина с кастомной моделью пользователя, корзиной, оформлением заказов и историей покупок.

## 🛠 Технологический стек
- Python 3.10, Django 5.x
- PostgreSQL 16
- Gunicorn, Docker & Docker Compose
- Bootstrap 5
